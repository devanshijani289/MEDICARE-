About MediCare+

MediCare+ is a student web technology project demonstrating responsive UI, client-side JavaScript, JSON/AJAX, local storage, Bootstrap, Tailwind CSS, Git workflow and static hosting concepts.

This is an educational project. It does not provide medical diagnosis or replace a healthcare professional.
